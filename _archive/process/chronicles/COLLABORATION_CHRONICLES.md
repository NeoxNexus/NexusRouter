# NexusRouter: 人机协作与架构演进编年史

> 此文档记录了在 NexusRouter 项目重构（Phase 1 & Phase 2）期间，人类架构师与 AI 智能体之间高阶 Pair Programming 的真实协作历程。
> 它不仅记录了代码的变迁，更记录了“从混沌到秩序”、“从简单实现到卓越工程”的思想碰撞全过程。

---

## 核心成就：一条清晰的研发协作脉络是如何制定的？

在这个项目中，我们并没有陷于“提需求-写代码”的低效循环，而是通过反复的**锚定、碰撞、纠偏和升华**，一步步打造出了高度清晰的研发脉络和严谨的工程底线。

### 阶段一：破局与立序（从混沌混沌到愿景锚定）

项目初期，代码库（原名 `ClawRouter`/`BlockRun`）背负着沉重的历史包袱，夹杂着大量支付、钱包和合作伙伴的冗余业务逻辑，定位极度模糊。

- **人类的战略决断**：果断“挥刀”，要求彻底剥离所有无关代码，将品牌统一为 `NexusRouter`。更关键的是，要求建立**全局的 `ROADMAP.md`** 和任务清单。
- **协作火花**：我们没有直接扑进代码库去删代码，而是先制定了 **Phase 1 的行动指南**。通过生成新的 Logo、重写 README（提炼出“三层 15 维分类器”的核心卖点），我们共同确立了项目**“极致智能路由”**的清晰定位。

### 阶段二：范式建立与底线死磕（从随意写码到工程严谨）

在进入实质开发时，人类架构师展现了非凡的工程要求，直接拉高了整个项目的质量底线。

- **人类的工程法则**：强制要求推行 **SDD（规范先行）+ TDD（测试先行）的融合模式**。下达铁令：“确认所有的测试用例都没有问题后，才能提交代码并进行下一步”。
- **协作火花**：AI 依照此标准，在编写每一行功能代码前必须先完成 `*.test.ts`。这使得我们在进行底层错误类型重排、模型前缀清理时，始终保持 300+ 个测试全绿的绝对安全感，为项目走向稳定可靠奠定了坚实基石。

### 阶段三：深度碰撞与架构升华（从简单糊弄到卓越设计）

在 Phase 2 接入 Claude Code 时，迎来了合作最深度的时刻。面对新需求，AI 极易犯“简单粗暴增加端点”的错误。

- **人类的专业引导机制**：
  1.  **防止闭门造车**：“不要简单新增端点，去 clone 竞品（`claude-code-router`）深度研究，吸收他们的长处再融合。”
  2.  **死守兼容与性能**：“任何修改必须考虑对现有 OpenClaw 兼容性，以及考虑代理延迟。”
  3.  **要求架构之美**：“恰当运用设计模式解耦，它俩场景不同，绝不能生搬硬套。”
  4.  **建立平权对话（极度关键）**：“**我的命令并非圣旨，你要以专业态度评判，不合理就放到【垃圾箱】并写明理由！**”
- **协作火花**：这些指令彻底激活了 AI 的系统架构师思维。通过反复讨论分类器权重（如 Claude 特有的 Haiku 后台任务 vs Sonnet 默认模式），我们最终摒弃了简单的路由映射，设计出了包含 **协议适配器 (Strategy) + Agent 插件注册 (Plugin) + 15维动态加权融合** 的高内聚统一代理架构，完美接入新功能，且旧版客户端零感知兼容。

### 阶段四：资产沉淀与模式固化（从一次性协作到长效机制）

代码交付并非终点，建立长治久安的机制才是核心。

- **人类的长效构建**：
  1.  引入强制的自动化流程：每完成一个 Phase 必须触发 **/code-review 工作流** 并落地深度评审报告。
  2.  提炼核心协作原则与架构底线，形成 **《NexusRouter 研发协作规范》(DEVELOPMENT_MANIFESTO.md)**。
  3.  **确立灯塔**：将 `ROADMAP.md` 确定为整个项目全局唯一的导航和真相源 (Source of Truth)，每次会话和每个新的智能体介入，都必须以此为起点。
- **协作火花**：我们将这段时间的默契沉淀为“项目铁律”并写入了代码库的 `.cursorrules` 文件。这意味着未来的每一次 AI 介入，都将自动继承这套极高标准的游戏规则。

---

## 复盘：ROADMAP 与任务清单是如何建立的？

我们建立核心 `ROADMAP.md` 的过程，是一次教科书般的**从“产品定位”到“战略规划”，再到“工程落地拆解”**的完整推演：

1. **清理包袱，明确“不做什么”（减法）**：
   达成共识剥离所有残余支付逻辑，确立 Phase 1 目标为基础清理与品牌统一。
2. **锚定优势，明确“我们是谁”（定位）**：
   梳理核心资产，发现毫秒级“三层渐进式分类器”的巨大潜能，提炼出“零配置智能路由”的核心愿景。
3. **对标竞品，规划未来路径（加法）**：
   通过深度调研分析 `claude-code-router` 等前沿工具的演进，洞察到“支持多 Provider 仅是起点，全自动智能路由才是终局”。由此顺理成章规划出从接入 Claude Code (Phase 2)、数据评测 (Phase 3)、可视化面板 (Phase 4) 到生产部署 (Phase 5) 的清晰路线图。
4. **落地 SDD + TDD，拆解执行规范**：
   将宏大的蓝图通过 SDD + TDD 的模式死死钉在执行文档中。每个任务在开发前都必须清晰定义接口规范、影响范围以及测试命令。结合 Task Tracker，让每一次的代码提交都具备严循的法度与可追溯的里程碑。

---

> 总结：在这里，人类是方向盘和灯塔，负责界定愿景、设定质量门禁和启发高维架构；AI 是不知疲倦的高效引擎，严格执行并不断突破工程极限。正是这种平权而严谨的碰撞，铸就了今日的 NexusRouter。
